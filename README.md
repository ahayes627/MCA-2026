\[As a new user of MuseScore, it is difficult to know what functions of the software need to be improved and what I need to improve in myself. Not coming from a trained music background, I thought the interface was easy to transcribe sheet music by sight. For example, I could look at a measure on my reference, then use that to figure out the type/length/placement of the note in MuseScore. However, for more complex features of the music, I found the software to be more challenging. In particular, I found myself frustrated when trying to transcribe a tuplet. Although I could see a function for tuplets in the toolbar and figure out how to mark the notes with a numbered bracket, it was not obvious how to assign the value of a triplet to three notes. However, I figured out a solution through a brief explanation in the r/Musescore Reddit thread. It was not possible to keep the notes as they were and assign them the value of a triplet retroactively. Instead, I had to go back and delete the three notes as I had transcribed them in MuseScore, first insert a note equal to the duration of the entire triplet group, then mark it as a triplet, and finally add in the actual notes. Thus, as a beginner, MuseScore works well for transcribing simpler elements of music, like note length, but it has a learning curve for more complex features.\]
